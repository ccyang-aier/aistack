## 顶层结构

| 路径 | 内容 | 作用 |
|---|---|---|
| `install.ps1` | 一键安装脚本 | 在目标机复制 skills/plugins/runtime，并注册本地 marketplace |
| `package-manifest.json` | 包摘要 | 记录迁移范围、排除项、插件列表 |
| `marketplace/marketplace.template.json` | marketplace 模板 | 供人工或 AI 参考；安装脚本会在目标机重新生成实际 marketplace |
| `plugins/` | 可迁移插件包 | 每个子目录都是一个完整插件根目录，含 `.codex-plugin/plugin.json` |
| `skills/agents/` | 用户级 agent skills | 来自 `C:\Users\17335\.agents\skills` |
| `skills/codex/` | 用户级 Codex skills | 来自 `C:\Users\17335\.codex\skills` 的可迁移子集 |
| `skills/system/.system/` | 系统 skill 快照 | 来自当前机器的 `.system` skill；安装脚本默认会复制，可用 `-SkipSystemSkills` 跳过 |
| `runtime/codex-primary-runtime/` | primary runtime 使能包 | 支撑 Documents/Presentations/Spreadsheets 等运行时能力 |
| `scripts/validate-package.ps1` | 自检脚本 | 校验 package 内必要文件是否存在 |

## 明确未打包内容

| 类型 | 未打包项 | 原因 |
|---|---|---|
| App connector / OAuth | `github`、`gmail`、`slack`、`figma`、`canva`、`biorender`、`heygen`、`picsart`、`shutterstock` | 真实能力依赖 ChatGPT connector/app 授权，不能通过文件复制恢复。 |
| 混合 connector 插件 | `openai-developers`、`data-analytics` | 含 app connector 引用；本地 MCP/skills 虽可迁移，但完整能力需要 connector 或自建 proxy。按本次边界未打包。 |
| 本机能力型插件 | `browser`、`chrome`、`computer-use` | 绑定本机浏览器、Chrome native host、桌面权限或 Codex app 后端。 |
| 敏感/机器状态 | `auth.json`、`.sandbox-secrets`、`state_*.sqlite`、`logs_*.sqlite`、`installation_id`、历史线程和缓存状态 | 避免泄露凭据、污染目标机状态或破坏当前机器。 |
