# Codex 一键迁移指南

目标：把本包复制到另一台 Windows 机器后，用最少操作安装本包内的可迁移 plugins、skills 和 primary runtime。

## 目标机前置条件

1. 目标机已经安装 Codex。
2. 目标机能运行 PowerShell。
3. 如果要使用 `build-ios-apps` 的完整 XcodeBuildMCP 能力，目标机需要 macOS/Xcode；Windows 目标机只能加载相关 skills，或通过远程 Mac MCP/proxy 补齐。
4. 如果要使用 `remotion`、`hyperframes`、`playwright` 等实际运行能力，目标机需要对应项目环境或 Node/npm/browser 依赖。

## 一键安装

在目标机 PowerShell 中进入迁移包目录：

```powershell
cd C:\AIWorks\26Coding\aistack\codex
```

先自检包完整性：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\validate-package.ps1
```

执行安装：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装脚本会做这些事：

1. 复制 `skills/agents/*` 到目标机 `~\.agents\skills`。
2. 复制 `skills/codex/*` 到目标机 `~\.codex\skills`。
3. 默认复制 `skills/system/.system/*` 到目标机 `~\.codex\skills\.system`。
4. 复制插件到目标机 `~\.codex\portable-codex-migration\plugins`。
5. 复制 primary runtime 到目标机 `~\.cache\codex-runtimes\codex-primary-runtime`。
6. 在目标机 `~\.codex\portable-codex-migration\marketplace.json` 生成本地 marketplace。
7. 备份目标机 `~\.codex\config.toml`，然后追加本地 marketplace 和插件启用项。

如果不想覆盖目标机自带 `.system` skills：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -SkipSystemSkills
```

如果目标机已经有 primary runtime，想跳过 1GB runtime 复制：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -SkipPrimaryRuntime
```

## 安装后操作

1. 完全退出并重启 Codex。
2. 新开一个 thread。
3. 在 composer 里输入 `@` 或打开 Plugins，检查是否出现 `codex-portable-migration` 来源。
4. 试用任意一个已迁移 skill 或插件，例如：

```text
$superpowers:using-superpowers 帮我确认当前会话可用的迁移 skill
```

或：

```text
@build-web-apps 帮我检查一个前端项目的 UI 结构
```

## 安装结果位置

目标机安装后，主要文件会落在：

```text
%USERPROFILE%\.agents\skills
%USERPROFILE%\.codex\skills
%USERPROFILE%\.codex\portable-codex-migration
%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime
```

目标机 `config.toml` 会追加类似内容：

```toml
[marketplaces.codex-portable-migration]
source_type = "local"
source = "C:\\Users\\<目标用户>\\.codex\\portable-codex-migration"

[plugins."build-web-apps@codex-portable-migration"]
enabled = true
```

脚本会先备份目标机原配置，备份文件名类似：

```text
%USERPROFILE%\.codex\config.toml.bak-codex-portable-YYYYMMDD-HHMMSS
```

## 可用性说明

本包内的 skill-only 插件和用户 skills，在完成复制、marketplace 注册、Codex 重启后应可加载。

以下能力取决于目标机环境：

| 能力 | 额外要求 |
|---|---|
| `build-ios-apps` 的 XcodeBuildMCP | Node/npm、网络、macOS/Xcode，或远程 Mac MCP/proxy |
| `build-macos-apps` 实际构建/运行 | macOS/Xcode |
| `documents/presentations/spreadsheets` | 已复制 primary runtime；若 Codex 版本差异过大，需升级目标机 Codex |
| `remotion/hyperframes/playwright` 实际运行 | 目标项目依赖、Node/npm、浏览器或 CLI 环境 |
| `imagegen` 系统 skill | 目标 Codex 是否提供 image generation 工具 |

## 本包不恢复的能力

本包不会恢复 GitHub/Gmail/Slack/Figma/Canva 等 connector 授权，也不会恢复 Browser/Chrome/Computer Use 这类本机权限型插件。那些能力需要在目标机重新授权、重新安装，或通过自建 MCP/proxy 另行接入。
